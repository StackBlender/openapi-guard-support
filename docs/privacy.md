# Privacy

OpenAPI Guard's current Free analysis is local-first. Source code, OpenAPI specifications, diagnostics, and repository metadata are processed locally and are not uploaded by OpenAPI Guard for analysis.

This statement covers the current Free endpoint-level analysis only. It does not describe Marketplace or IDE telemetry, crash reporting provided by third parties, network behavior of unrelated extensions or dependencies, or planned products and features. Review the policies of the distribution platform and IDE separately.

Do not post sensitive material in this public repository. Before submitting an issue or pull request, remove secrets, credentials, license keys, personal and customer data, proprietary source code, private contracts, private OpenAPI definitions, and sensitive logs.

This page is the public summary of the current product's privacy behavior. It is not legal advice or a description of features that have not launched.
