# Contributing

Contributions to this public support repository may include documentation corrections, sanitized examples, minimal reproduction cases, and compatibility notes. Product implementation code is proprietary and is not accepted here.

Before opening a pull request:

1. Make the contribution safe to publish permanently.
2. Remove credentials, secrets, license keys, personal or customer data, proprietary code, private API definitions, and sensitive logs.
3. Keep examples small, deterministic, and relevant to OpenAPI Guard.
4. Run any checks documented alongside the files you change.
5. Explain what changed and how it was verified.

By contributing, you agree that your contribution is licensed under this repository's [MIT License](LICENSE). Only contribute examples and other material that you have the right to publish under that license. The maintainers have not yet confirmed whether unsolicited external pull requests will be accepted; opening one does not guarantee review or inclusion.
