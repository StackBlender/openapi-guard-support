# Examples

These intentionally public, sanitized examples demonstrate the smallest matching OpenAPI/Spring endpoint pair:

- [Spring Java](spring-java/README.md)
- [Spring Kotlin](spring-kotlin/README.md)

Each example contains an OpenAPI 3.0 contract and a matching controller. They are source fixtures rather than standalone applications, so no build output or dependency lockfile is included. Copy the files into a compatible Spring Boot project to run them.

The examples are licensed under the repository's [MIT License](../LICENSE). They use fictional data and must not be replaced with private API definitions or proprietary source.
