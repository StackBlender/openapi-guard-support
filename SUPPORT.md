# Support

Start with the relevant [product documentation](README.md#product-status) and troubleshooting guide. Please use only sanitized, intentionally public material in this repository.

## Where to ask

| Need | Channel |
| --- | --- |
| Reproducible product bug | Choose the matching [GitHub issue form](https://github.com/StackBlender/openapi-guard-support/issues/new/choose) |
| Feature request | The [feature request form](https://github.com/StackBlender/openapi-guard-support/issues/new?template=feature-request.yml) |
| Usage question | Documentation first; if it does not answer the question, use the feature request form and select “Documentation” |
| Billing or license problem | A private billing channel will be published before paid licensing launches; do not open a public issue |
| Security concern | Use [GitHub private vulnerability reporting](https://github.com/StackBlender/openapi-guard-support/security/advisories/new) |

Support in this repository does not include guaranteed response times, individual debugging, a version-support commitment, refunds, or an SLA.

## Safe reports

Provide a minimal reproduction whenever possible. Remove secrets, license keys, credentials, personal or customer data, proprietary source, private API definitions, and sensitive logs before posting. If safe sanitization is not possible, do not attach the material publicly.
